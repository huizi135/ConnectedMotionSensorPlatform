# 阶段讲解与验收文档约定

每完成一个 Phase，在 docs/ 下单独保存 PhaseN_Explanation_Interview_QA_ZH.html，中文即可。保留已有双语架构、案例和 ADR 文档。

阶段复盘必须包含：结果与证据、烘焙类比、实际流程、模块边界、技术决策与代价、故障恢复、数据可靠性边界、测试方法、面试问答与追问。技术决策采用背景、决定、替代方案、代价、重新评估条件的简短 ADR 格式，必要时链接正式 ADR。

每条操作指令解释用途、预期结果和失败时停止位置；遇到相关面试要点单独提示。按阶段验收推进，不提前宣称未实现或未验证的能力。
