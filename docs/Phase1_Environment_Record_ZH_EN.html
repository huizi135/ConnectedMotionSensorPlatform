Why a virtual environment 为什么创建虚拟环境

A repository-local .venv isolates this project's Python packages. It is not a container and does not isolate the operating system or networking. Call its interpreter directly to avoid ambiguity and activation-policy changes. 仓库内 .venv 隔离本项目 Python 依赖，不等于操作系统或网络隔离。直接调用其 python.exe，可避免全局解释器混用，也无需修改执行策略。
