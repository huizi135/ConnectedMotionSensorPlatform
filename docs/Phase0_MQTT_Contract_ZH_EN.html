What a contract does 契约的作用

A contract is the shared boundary between independent Python and .NET implementations, similar to a DTO plus validation rules. It defines required fields, units, identity and time semantics. 契约相当于跨语言共享的 DTO 加校验规则；明确字段、单位、身份与时间语义，让模块独立演进。

Layer 层次Checks 检查
JSON decoding 解码Syntax, duplicate keys, finite numbers · 语法、重复键、有限数值
Schema 模式Fields, types, ranges, timestamps and UUIDs · 字段、类型、范围、时间与 UUID
Envelope 消息封套Supported topic and device identity equality · Topic 合法及设备身份一致
Later runtime 后续运行Deduplication, reconnects, QoS, Will and durable storage · 去重、重连、遗嘱与持久化

Wire decisions 传输约定

Telemetry: QoS 1, retain false, one sample per message. Status: QoS 1, retain true. Device IDs use lowercase letters/digits/underscore/hyphen and are 1–64 characters; first character is a letter or digit. 读数单样本、不保留；状态保留。设备 ID 使用小写字母、数字、下划线及短横线，长度 1–64，首位字母或数字。

Use UTC Z timestamps with up to six fractional digits, m/s² including gravity and rad/s. Sampling and reception time are separate. Preserve messageId, streamId and sequence on retries. 时间使用 UTC Z，最多六位小数；加速度含重力，单位 m/s²；角速度 rad/s；重试保留样本身份与时间。

reportedAt is required. It may be null only for offline status, allowing a preconfigured Will without inventing a future disconnection time. batteryPercent is optional, 0–100, and is omitted when unknown. reportedAt 必填，仅 offline 允许 null；遗嘱不伪造未来断线时间。电量可选，未知时省略。

Unknown optional fields are allowed, while known required fields remain validated. simulation is optional and excluded from detector inputs. 未知可选字段允许扩展；已知字段仍校验。simulation 标签可省略，检测器不读取它。

Important implementation detail 实现注意

JSON Schema format can be annotation-only. Configure explicit date-time and UUID assertions and test impossible dates. Schemas cannot compare a payload to an MQTT topic or prove persistent storage. format 可能仅作注释，需要显式启用验证并测试非法日期。Schema 无法比较 Topic，也无法证明入库。
